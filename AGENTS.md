# Oracle Formation Agent Map

This monorepo can be opened independently from the Usine hub, including in
Codespaces. Read `CLAUDE.md` and `AI-CONTEXT.md` before editing.

Public contact email for legal pages, footers, llms files, and structured data:
`info@yann-lephay.com`.

Useful commands:

```bash
npm run dev
npm run build
npm run lint
npm run dev:dp
npm run build:dp
npm run lint:dp
```

Do not assume the Usine hub path exists. For app-specific work, inspect
`apps/<name>/package.json`, `src/app`, `src/lib/metadata.ts`, and
`src/lib/structured-data.ts`.
